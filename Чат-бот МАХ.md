* Создание чат-бота MAX: https://dev.max.ru/docs/chatbots/bots-create

* для создания бота профиль организации должен быть верифицирован
* бот создаётся по ссылке https://business.max.ru/self
* ник создаётся автоматически по шаблону `idИНН_bot`
* токен чат-бота можно найти на [платформе](https://business.max.ru/self) в разделе **Интеграция** → **Получить токен** — находится в поле с одноимённым названием
* токен — уникальный идентификатор бота, с помощью которого он будет взаимодействовать с [[API MAX]]
* для одной организации доступно создание 5 ботов
* Каждый бот должен пройти [модерацию](https://dev.max.ru/docs/chatbots/bots-create#Этап 2. Модерация). Проверка занимает до 48 часов по рабочим дням.
* Для бота можно создать сценарий с использованием конструктора. См. https://dev.max.ru/docs/partners-integration#Конструкторы%20ботов
* Настройки бота можно изменить только на платформе MAX для партнёров — отредактировать их в мессенджере MAX не получится.
* В бот можно добавить [[Мини-приложения MAX|мини-приложение]]
